# Sales Performance Regression Analysis

**Author:** Mitchell Fields  
**Focus:** Regression Modeling, Sales Analytics, Predictive Insights  

## 🧭 Overview
This project analyzes sales data to identify key drivers of performance and evaluate predictive relationships between business variables. The goal is to understand which factors most strongly influence sales outcomes and how regression models can support data-driven business decisions.

Advanced regression modeling techniques were applied, and findings were summarized in a presentation format for clear stakeholder communication.

## 🔍 Analysis Performed
- Explored relationships between sales and key explanatory variables.
- Built and evaluated multiple regression models to explain and predict sales performance.
- Assessed model fit, statistical significance, and practical relevance.
- Interpreted model outputs in a business context.

## 📊 Modeling Approach
- Multiple linear regression
- Model comparison and evaluation
- Emphasis on interpretability and actionable insights

## 🧰 Tools Used
- **Statistical Modeling:** regression analysis  
- **Tableau:** visualization and exploratory analysis  
- **PowerPoint:** presentation of modeling results  
- **Git / GitHub:** documentation and version control  

## 🧠 Key Insights
- Several predictors demonstrated statistically significant relationships with sales outcomes.
- Regression results identified high-impact variables that can guide performance optimization.
- Model outputs provide a foundation for forecasting and scenario analysis.
